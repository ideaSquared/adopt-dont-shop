# scripts/

Utility scripts referenced from the root `package.json` or mounted into containers. All scripts are cross-platform unless noted.

## Reference

| Script                              | Invoked via                                                           | Purpose                                                                                                                                                                                                                                                                                                       |
| ----------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bootstrap.mjs`                     | `pnpm bootstrap`                                                      | One-shot onboarding: checks Node, seeds `.env`, generates secrets, runs `pnpm install --frozen-lockfile`, builds libs, validates env, and installs Playwright browsers. Pass `-- --skip-playwright` to skip the ~200 MB browser download.                                                                     |
| `generate-secrets.mjs`              | `pnpm secrets:generate`                                               | Print fresh JWT/session/encryption/upload/principal-signing secrets plus Postgres/Redis/Grafana passwords to append to `.env`. Pure Node — works on Windows/macOS/Linux without OpenSSL.                                                                                                                      |
| `validate-env.ts`                   | `pnpm validate:env`                                                   | Check `.env` against the required-variable list and warn on missing/insecure values. Uses the shared Zod schema in `@adopt-dont-shop/lib.validation` so the CLI gate and the backend boot validator stay in lockstep.                                                                                         |
| `check-lib-tests.mjs`               | `pnpm check:lib-tests`                                                | CI guard: fails when a `lib.*` package ships with zero test files. Allowlist lives inside the script.                                                                                                                                                                                                         |
| `create-new-app.js`                 | `pnpm new-app`                                                        | Scaffold a new `app.<name>` package with Vite + React + workspace wiring.                                                                                                                                                                                                                                     |
| `create-new-lib.js`                 | `pnpm new-lib`                                                        | Scaffold a new `lib.<name>` package with TypeScript + Vitest + workspace wiring.                                                                                                                                                                                                                              |
| `generate-test-attachments.js`      | `pnpm generate:attachments`                                           | Generate sample chat attachments (images + PDFs) into `uploads/chat/` for the `20-emily-attachment-test` seeder.                                                                                                                                                                                              |
| `snapshot-postgres.sh`              | `.github/workflows/backup.yml` (nightly `0 2 * * *`)                  | `pg_dump` of the prod database → S3. Run on the host by `backup.yml`; a host cron entry is a documented alternative. See `docs/db-backup-runbook.md`. Bash — Linux/macOS only.                                                                                                                                |
| `snapshot-uploads.sh`               | `.github/workflows/backup.yml` (nightly `0 2 * * *`)                  | `aws s3 sync` of the `uploads` Docker volume → S3. Run on the host by `backup.yml`; a host cron entry is a documented alternative. See `docs/operations/snapshot-policy.md`. Bash — Linux/macOS only.                                                                                                         |
| `restore-postgres.sh`               | operator on host; `.github/workflows/backup-restore-drill.yml`        | Restore a snapshot from S3 (or a local `*.sql.gz`) into a target DB via `psql` (not `pg_restore`); refuses the live DB without `CONFIRM_RESTORE=I_UNDERSTAND`. See `docs/db-backup-runbook.md`. Bash.                                                                                                         |
| `wait-for-services.sh`              | `deploy.yml` / `rollback.yml` (scp'd to host)                         | Shared health-gate loop: polls each `service:port` for `service_healthy` with a retry/timeout contract; used by the deploy and rollback workflows. Bash.                                                                                                                                                      |
| `write-redis-secret.mjs`            | preflight of `pnpm docker:dev` / `pnpm dev:services`                  | Materialises `./secrets/redis_password` from `.env`'s `REDIS_PASSWORD` so the `redis` container can read its `--requirepass` from a file (ADS-878).                                                                                                                                                           |
| `docker-dev.mjs`                    | `pnpm docker:dev` (+ `:detach`/`:build`/`:client`/`:admin`/`:rescue`) | Preflight-checked dev-stack launcher: Docker check, `.env` validation, Redis-port check, stale-volume detection, then `docker compose up`. See `docs/DOCKER.md`.                                                                                                                                              |
| `docker-dev-entrypoint.sh`          | baked into `Dockerfile.dev`                                           | Non-root step-down entrypoint for the dev image (ADS-881) — fixes ownership of the anonymous-volume `node_modules` trees before dropping privileges. Do not invoke manually.                                                                                                                                  |
| `seed.mjs`                          | `pnpm db:seed`                                                        | Seed the fixed dev/e2e personas across services (auth, pets, rescue, applications, chat).                                                                                                                                                                                                                     |
| `spam.mjs`                          | `pnpm db:spam`                                                        | Seed the realistic synthetic tier — adopters, rescues, a photo'd pet catalogue, applications, chats, notifications. Idempotent.                                                                                                                                                                               |
| `audit-bulk.mjs`                    | CI security workflow (replaces `pnpm audit`)                          | Dependency vulnerability audit via npm's _bulk advisory_ endpoint (npm retired the quick-audit endpoint `pnpm audit` calls). Honours the ADS-903 severity policy and `.trivyignore`-style exemptions.                                                                                                         |
| `ratchet-coverage.mjs`              | `pnpm ratchet:coverage`                                               | Raise a package's coverage-threshold floor in its `vitest.config.ts` towards current measured coverage (never lowers it); `-- --package <path>`.                                                                                                                                                              |
| `generate-dependency-docs.mjs`      | `pnpm generate:dependency-docs`                                       | Regenerate `docs/libraries/*-consumers.md` and the `docs/README.md` library-consumer block.                                                                                                                                                                                                                   |
| `generate-task-index.mjs`           | `pnpm tasks` / `pnpm commands` / `pnpm tasks:write`                   | Read every workspace `package.json` and emit the categorised script index to `docs/tasks.md` (ADS-795, ADS-949).                                                                                                                                                                                              |
| `check-csp-headers.mjs`             | `pnpm check:csp`                                                      | Guard: fail if an nginx CSP allows `unsafe-inline`/`unsafe-eval`, or a prod SPA vhost is missing its CSP header.                                                                                                                                                                                              |
| `check-docker-pinning.mjs`          | `pnpm check:docker-pinning`                                           | Guard: fail if a Dockerfile/compose base image is not pinned by digest.                                                                                                                                                                                                                                       |
| `check-docs-freshness.mjs`          | `pnpm check:docs-freshness`                                           | Report (non-blocking): broken internal/external doc links and docs untouched for 12+ months.                                                                                                                                                                                                                  |
| `check-docs-script-references.mjs`  | `pnpm check:docs-script-refs`                                         | Guard: fail if a doc references a `pnpm run <script>` that doesn't exist.                                                                                                                                                                                                                                     |
| `check-env-example.mjs`             | `pnpm check:env-example`                                              | Guard: fail if a var `validate-env.ts` requires is missing from `.env.example`'s REQUIRED banner.                                                                                                                                                                                                             |
| `check-form-primitives.mjs`         | `pnpm check:forms`                                                    | Ratchet: fail if the apps add raw `<input>`/`<select>`/`<textarea>` or `TextInput` beyond the persisted ceiling.                                                                                                                                                                                              |
| `check-no-test-only.mjs`            | `pnpm check:no-only`                                                  | Guard: fail if a committed test uses a focused test (`.only` / `fdescribe` / `fit`).                                                                                                                                                                                                                          |
| `check-overrides-documentation.mjs` | `pnpm check:overrides-docs`                                           | Guard: fail if a `pnpm.overrides` entry has no matching `overridesDocumentation` note (ADS-1113).                                                                                                                                                                                                             |
| `check-readmes.mjs`                 | `pnpm check:readmes`                                                  | Report (non-blocking): workspace READMEs missing a section from the README templates.                                                                                                                                                                                                                         |
| `check-stale-overrides.mjs`         | `pnpm check:stale-overrides`                                          | Report (non-blocking): `pnpm.overrides` pins upstream has moved past — removal candidates (ADS-1112).                                                                                                                                                                                                         |
| `check-storybook-coverage.mjs`      | `pnpm check:stories`                                                  | Report Storybook story coverage for `packages/lib.components/src/components/ui/`.                                                                                                                                                                                                                             |
| `check-workflow-paths.mjs`          | `pnpm check:workflow-paths`                                           | Guard: fail if a GitHub Actions workflow references a path that doesn't exist.                                                                                                                                                                                                                                |
| `check-workspace-consistency.mjs`   | `pnpm check:workspaces`                                               | Workspace structural-drift guard (ADS-622). Verifies required scripts per `lib.*`/`app.*` package, `vitest.workspace.ts` coverage, `vite.shared.config.ts` `getLibraryAliases()` coverage, absence of nested `pnpm-lock.yaml`, and absence of stale Jest references. Wired into the `workspace-drift` CI job. |
| `check-docs-index.mjs`              | `pnpm check:docs-index`                                               | Fails CI when a markdown file under `docs/` is not linked from `docs/README.md` (ADS-716). Allowlists `docs/README.md` itself and `docs/legal/**`. Wired into the `workspace-drift` CI job (ADS-984).                                                                                                         |
| `init-postgis.sql`                  | mounted into `database` container at `/docker-entrypoint-initdb.d/`   | Enables the PostGIS extension on first DB init. Runs automatically — do not invoke manually.                                                                                                                                                                                                                  |

Helpers live in two subdirectories:

- `scripts/lib/` — shared helpers (e.g. `template-engine.mjs`) consumed by the scaffolding scripts.
- `scripts/templates/` — file templates used by `create-new-app.js` / `create-new-lib.js` to scaffold new workspaces.

## Adding a new script

1. Drop the file in `scripts/`.
2. Add an entry to root `package.json` `scripts` so it's discoverable via `pnpm run`.
3. Add a row to the table above.
